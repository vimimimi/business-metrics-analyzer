# Ответы на контрольные вопросы

## 1. Чем отличается Git от GitHub?

Git — это распределённая система контроля версий.

GitHub — это облачная платформа для хранения Git-репозиториев и совместной работы.

## 2. Для чего используется виртуальное окружение Python?

Виртуальное окружение Python — это изолированная среда, которая позволяет не смешивать зависимости разных проектов.

## 3. Что такое commit, branch, remote, pull request?

**Commit** — фиксация изменений в истории проекта.

**Branch** — отдельная ветка разработки.

**Remote** — удалённый репозиторий.

**Pull Request (PR)** — запрос на слияние изменений из одной ветки в другую.

## 4. Зачем нужен файл .gitignore?

Файл `.gitignore` определяет, какие файлы и папки не должны попадать в репозиторий.

Например, туда можно добавить виртуальное окружение `.venv/`, кэш Python и другие временные файлы.

## 5. Как организовать командную работу над бизнес-приложением с помощью Git?

Разработчики работают в отдельных ветках. Каждый разработчик вносит изменения, создаёт commit и отправляет свою ветку на GitHub. После этого создаётся Pull Request, другой разработчик проверяет изменения, и после проверки выполняется слияние с основной веткой `main`.

## 6. Какие файлы обязательно должны быть в репозитории учебного проекта?

Основными файлами учебного проекта являются `README.md`, `.gitignore`, `requirements.txt` и `main.py`. Также в рекомендуемой структуре проекта предусмотрена папка `docs/` с файлом `business_requirements.md`.

## 7. Что произойдёт, если два разработчика изменят один и тот же файл в разных ветках?

При слиянии изменений может возникнуть конфликт (merge conflict), если разработчики изменили одни и те же части файла. Конфликт необходимо разрешить, после чего изменения можно объединить.
